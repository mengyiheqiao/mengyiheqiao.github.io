百宝匣：把常用工具和踩过的坑装进一个箱子

发表于2026-10-29|更新于2026-10-29|方法
|浏览量:

我最近做了个小软件，叫百宝匣。

灵感来自《我的世界》里的末影箱：一个随手就能打开、什么都装得下的箱子。

为什么要做它

起因是三件让我很烦的事：

  • 工具太散：常用的网址、文件夹、软件，还有从 GitHub 下的小项目，散得到处都是。每次要用都得翻半天，项目怎么启动也早忘了。
  • 踩过的坑总忘：比如怎么解除复制限制、csgo 的 demo 怎么看，当时明明解决过，过两个月又得从头查。
  • 换台电脑就两手空空：在学校机房、别人的电脑上，拿不到自己的文件，也用不了自己的工具。

所以我干脆做一个箱子，把这些全装进去。

它能做什么

工具区：一点就开

  • 网址、文件夹、软件、本地项目，每个都是一个抽屉，点一下就打开。
  • 本地项目会自动启动，等它准备好了再打开网页。
  • 组合技：一个按钮按顺序做好几件事，比如先开代理，等 3 秒，再打开某个项目。
  • 贴上 GitHub 项目地址，就能自动下载、识别启动方式，以后还能一键检查更新。

记忆区：自己的资料库

  • 用 Markdown 写说明，截图直接粘贴进去。
  • PDF、电子书、Word、Excel、PPT 拖进来就能看，里面的字都能搜。
  • 用彩色活页分类，配合浏览器插件，网页上选中文字点一下就存进来。

随身口袋 + 末影箱：东西跟着人走

  • 文件放进口袋，会加密后存进你自己的 GitHub 私有仓库。到了机房，连上同一个末影箱就能拿到。
  • 临时模式：在别人的电脑上用完，关掉百宝匣就清干净，不留密码、令牌和文件。
  • 没装百宝匣的电脑，用浏览器打开网页版也能取文件。

还有一些好玩的

  • AI 管家：接上 DeepSeek、通义千问等 AI 后，她会翻你的资料回答问题，并标出出处。
  • 截图识字：框选屏幕上的字，自动复制。
  • 皮肤：自带原皮、极简、二次元、星空四套皮肤，还能带一个会眨眼的看板娘。

适合谁

  • 电脑上工具、项目一大堆，总是找不到、记不住怎么用的人。
  • 喜欢折腾，想给自己攒一个”踩坑笔记本”的人。
  • 经常在机房、公司等公共电脑和自己电脑之间来回倒腾文件的学生和上班族。

放心用

  • 数据都在你自己电脑上：不用注册，没有服务器，也不收集任何信息。
  • 加密在本机完成：末影箱的文件在你电脑上加密后才上传，GitHub 上只能看到一堆乱码。
  • 免费开源：MIT 协议，随便用、随便改。

下载

  • 项目主页：github.com/mengyiheqiao/baibaoxia
  • 下载：Releases 页面
    • Windows 用户下载桌面版 Baibaoxia-Desktop-x.x.x.zip，解压后双击 百宝匣.exe 就能用。
    • macOS 和 Linux 可以用网页版（需要先装 Node.js）。
  • 详细用法：使用手册

还在一点点更新。觉得好用的话，欢迎点个 Star；有想法的话，可以提 Issue，也可以在下面留言~
